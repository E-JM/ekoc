# 9. Standard Library

This clause specifies the semantics of the standard library. Annex C is the
authoritative inventory of signatures and members; a signature appears here
only where a rule requires it. A `!` marks a world-touching service and a `?`
an open bit; capability and world-bit typing is specified in Clause 7.9.
