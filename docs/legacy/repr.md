# eko 值表示 —— 装箱、共享与内存

状态:设计定案(2026-10)。结论先行,理由随文。
本文关闭 need.md 规范洞"递归类型与值表示";递归型声明面开门于
type.md §8。eko 无虚拟机、直编机器码——表示与内存没有"运行时替
我管"的退路,本文三问一次裁齐:值怎么摆(装箱)、名字怎么给
(共享)、内存怎么收(计数)。

## 0. 裁定一览

| # | 裁定 |
|---|---|
| 1 | 复合值以不可变堆对象表示;名字、参数、字段、元素、载荷、捕获槽持引用——绑定/传参/捕获 O(1) 共享,深拷词汇不存在 |
| 2 | 标量直存:Bool/Char/Int/UInt/Float 走寄存器与槽;Unit 零尺寸;Never 无表示 |
| 3 | **递归位恒间接**:递归型的自引用处恒为指针——递归型尺寸恒有限,开门零新增检查(type.md §8) |
| 4 | 值语义观察:`==`/show/模式匹配按结构递归;无身份比较、无取址、无回写——共享对程序不可观察 |
| 5 | 内存自动:无 free、无指针词汇;无 finalizer、无析构、无回收时序——回收不是可编程事件 |
| 6 | **环定理**:值不可变 + 严格求值 + 捕获快照 ⟹ 堆图恒为 DAG,环结构性不可能 |
| 7 | 内存策略 = 引用计数(规范级):归零即回收,无停顿、无根扫描;跨任务原子计数(io-world §8) |
| 8 | 无环回收器、无 weak/unowned——环不存在,不为不存在的病配药 |
| 9 | 优化面全开:拆箱、栈配、逃逸分析、计数消减皆实现域自由;前提是裁定 4/5 的不可观察 |
| 10 | **泛型单态化**(规范级):实例化编译期展开,布局随实例;泛型体随接口走(module.md §6) |
| 11 | 内存耗尽即中止:进程级 abort,不可捕——与栈溢出同款(loop.md §4) |

## 1. 引用流动,值观察

主轴一句:**名字持引用,运算看结构。**

```eko
p2   := p                    // O(1):共享,零拷贝
big2 := big                  // 同一 String,不复制
q    := p.with({age: 37})    // 顶层浅拷,未动字段共享(derive.md §6)
n2   := p2.name              // 字段取值 O(1);p2 与 p 是同一对象
```

| 值类 | 表示 |
|---|---|
| 标量(Bool、Char、Int、UInt、Float) | 直存,寄存器与槽,无堆 |
| 复合(记录、元组、列表、字典、ADT、String、闭包) | 不可变堆对象,引用流动 |
| 不透明(capability、句柄、Range) | 实现域;句柄含代际(io-world §4) |
| 零员(Unit、Never) | Unit 零尺寸;Never 无表示(never.md §5) |

- 规范承诺的是**模型与量级**(裁定 1/2 与 §7 成本表),不是每个值
  的字节落位——§5 优化面照此全开。递归位恒间接(裁定 3)是唯一的
  硬布局规则,它撑起 §2 的零检查开门。
- String 是堆上不可变 UTF-8(char.md);绑定共享,`++` 全拷。
- **捕获快照**:闭包捕获**名字当场的值**(共享);`:=` 重绑定不回写
  已捕获环境——新值归新名,旧环境不动。捕获语义就此一句定案。

## 2. 递归型开门(与 type.md §8 对读)

递归位恒指针,两个直接后果:

1. **尺寸恒有限**:`Succ Nat` 的载荷是一指针,展开停在指针处——
   递归型开门**零新增合法性检查**;无基例的递归型合法而零居留,
   居留性不作检查(never.md 同精神)。
2. **derive 必终止**:show/==/< 按结构递推生成递归函数,终止由
   §3 环定理保证——值有限,遍历必停。

```eko
Nat:     type = Zero | Succ Nat
IntList: type = Nil | Cons [Int, IntList]
Tree:    type t = Leaf t | Node [Tree t, Tree t, t]
Person:  type = [name: String, friends: []Person]   // 递归穿容器

sum: (xs: IntList) -> Int =
    case xs:
        Nil         -> 0
        Cons {h, t} -> h + sum(t)      // 结构递归;栈保证按 loop.md 三词汇
```

互递归(模块内)与自递归同权;递归穿应用(`Node (Tree [t, t])`)
照常——递归位仍是指针。

## 3. 环定理

主轴一句:**新值只引用旧值,堆上边只降不升——DAG 由构造序免费成立。**

一个值构造完成,当且仅当其全部子值已构造完成(严格求值——组合子
即刻遍历,loop.md)。按完成时刻给堆对象编号,一切边从大号指向
小号;回环需要三条通道之一,全被既有裁定封死:

| 通道 | 封死它的 |
|---|---|
| 可变回写:造好后改字段回指 | 值不可变(expr.md) |
| 惰性悬置:先占位后填充 | 严格求值;绑定先值后名 |
| 捕获自槽:闭包环境回指未完成的绑定 | 捕获快照(§1);自引用/互引用是**模块顶层具名绑定**的编译期名字事实,经静态槽解析——块级无自引用(名字未得值即用,编译错误;若痛,提升是机械变换,另立) |

推论四条:

- **引用计数完备**(裁定 7):归零即整图释放,无泄漏通道。
- **无 weak/unowned**(裁定 8):强弱引用是可变对象图的自救词汇;
  eko 无环,词汇无处安放。
- **derive 必终止**:见 §2。
- **Conc 共享堆安全**(io-world §8):任务捕获快照,跨任务共享即
  计数,环仍不可能。

panic 不 unwind(io-world §4 既有):abort 即全弃,计数不跑——
两档相认,无需协商。

## 4. 内存策略:引用计数

主轴一句:**内存是编译器的事,不是一个运行时。**

RC 的全部基建是三个词:alloc、retain、release——长在代码生成里,
不是一座运行时;嵌入契约(D5)因此朴素:宿主持值即持引用,无根
注册、无停顿协商。

**规范级承诺**(一切合规实现):

- 自动:无悬垂、无 double-free、无 free 词汇——内存安全是语言的
  地板,不是能力(与能力哲学分界:权限显式,地板免费);
- 确定性:引用归零即回收,无停顿、无根扫描。确定性对 eko 程序
  不可观察(裁定 5),对宿主可观察(D5)——承诺写给宿主;
- 量级不劣:批量释放、计数消减属实现域;**消减只可提前回收,
  不可推迟**。

**旗舰基线**(描述性):每对象一计数;绑定/传参/捕获/入容器
retain,出域与重绑定 release;归零释放,子引用迭代释放;跨任务
共享对象原子计数,任务私有免原子;编译期证明独占即免计数(Swift
ARC 同款既定路线)。

流式有界是工程红利:`xs.each` 扫过即释,长流常驻 O(1)——如实
记,这是策略选择的账,不是逐条验收的契约。内存耗尽即中止
(裁定 11),与栈溢出同款。

### 被否决备选

| 方案 | 否决理由 |
|---|---|
| 追踪 GC(分代/并发) | 确定性承诺不达标;根扫描与停顿把内存变成运行时—宿主协商;环定理下追踪是多余基建 |
| 所有权/借用 | 值自由流动 + 闭包自由捕获是 eko 气质;借用让签名携带生命周期域,每个绑定多一层心智税 |
| RC + 环收集器(ORC) | 为不存在的环配药(§3) |
| 区域/arena 显式化 | 闭包逃逸自由,区域推断不可靠;留作实现与宿主域技巧 |
| 手动管理 | 内存不是能力,是地板;地板不显式 |

## 5. 优化面:不可观察的地基

观察面为零,优化面全开。eko 没有一扇窗看进表示:无身份比较、无
mutation、无 finalizer、无内存占用词汇——裁定 4/5 的四禁。

| 优化 | 做法 | 不变量 |
|---|---|---|
| 拆箱 | 小型不可递归复合内联进槽 | 递归位恒间接不破坏 |
| 栈配/逃逸 | 不逃逸对象栈上直构 | 值不逃逸证明 |
| 计数消减 | 静态证明独占即免 retain/release | 只提前,不推迟 |
| 共享体 | 指针一致的单态化实例复用同机器码 | §6 链接期 |

主轴一句:**规范定形状与量级,实现定字节与时序。**

## 6. 泛型单态化

type.md §5"按 t 实例化展开"升为规范级策略:

- **布局随实例**:`[]Float` 元素直存 8 字节槽,`[]Person` 元素是
  引用——数值容器零装箱税,单态化的直接红利。
- **泛型体随接口走**(module.md §6 注记):泛型函数的体是接口的
  一部分,下游实例化在下游展开;同实例机器码链接期去重。
- 变量能力面(==/show,generics.md §3.4)随实例落具体派生——
  运行时无类型信息、无分派表;变体标签是值的结构,不是类型身份
  (type.md 裁定 4)。
- 代价如实记两笔:代码体积随实例数增长(去重与共享体是恒久功课);
  实例化按调用图展开,展开不终止(多态递归造无穷实例)即编译错误
  ——类型检查仍免费(generics.md §3.1),付费的只有机器码展开。
- 替代(统一装箱 + 运行时字典)不取:类型身份编译期完成的直接
  延伸,不留运行时分派面。

## 7. 成本契约(量级)

| 操作 | 量级 |
|---|---|
| 绑定/传参/捕获/入容器(复合) | O(1) 引用 |
| 标量算术、字段取值 `p.name` | O(1) |
| `p.with({...})` | O(顶层字段数) 浅拷;未动字段共享;嵌套部分字面量按路径付 |
| `xs ++ ys`(列表) | O(\|xs\|) 新节点;ys 全共享 |
| String `++` | O(n) 全拷;字典合并量级属实现域(持久化结构) |
| `==`/show/inspect | O(结构大小) |
| 深结构递归 | 随数据深;栈保证按 loop.md 三词汇分层 |

## 8. 与各档接缝

- type.md §8:递归开门;§7 形适配的同形判定在递归位按名相等——
  形状展开比对,环不进判定。
- generics.md §4.3 待定注就此关闭;§3.4 变量能力面随单态化落地。
- derive.md §6 `with`:浅拷语义由本文定成本,词汇不新增。
- io-world.md §4:句柄代际、泄漏允许、panic abort 照旧——内存
  策略不改资源故事;"finalizer 不作承诺"在此升格为永久裁定
  (裁定 5)。
- loop.md §4:栈溢出条款;本文补内存耗尽同款(裁定 11)。
- FFI/二进制域(Bytes、布局对译)另立;本文的表示承诺不外泄。

## 9. 禁止清单

- **身份比较(`===`/physical eq/取址比较)**——使共享可观察,拆毁
  §5 全部优化面;`==` 结构相等已是全部。
- **指针/取址/手动 free 词汇**——内存安全是地板;FFI 另议。
- **finalizer/destructor/drop**——回收不可观察是优化地基;资源走
  代际句柄 + `with_*` 既有机器。
- **weak/unowned 引用**——环结构性不可能(§3)。
- **深拷/浅拷词汇**——共享即全部;确需独立副本,逐字段重建
  (type.md §7.1)。
- **GC 暴露词汇(`gc()`/暂停控制/内存回调)**——内存不是可编程
  事件。

## 10. 速查

```
p2 := p                     // O(1) 共享;深拷词汇不存在
q := p.with({age: 37})      // 顶层浅拷,未动字段共享
Nat: type = Zero | Succ Nat // 开门:Succ 载荷即指针,尺寸恒有限
xs ++ ys                    // O(|xs|);ys 全共享
[]Float 元素直存            // 单态化:数值容器零装箱税
新值只引用旧值              // 环定理:RC 完备,无环回收器
无 finalizer/weak/gc()      // 回收不可观察,优化面全开
```
