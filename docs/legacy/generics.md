## 0. 裁定一览

| # | 裁定 |
|---|---|
| 1 | 声明 binder:`Name: type 变量* = Rhs`——`type` 之后、`=` 之前;应用按位左→右填充 |
| 2 | 应用并置、无逗号:`Value Int Float`;实参为 arrow-free atom,`->` 终止链 |
| 3 | 幻影参数:binder 必须出现在 RHS,声明期报错 |
| 4 | 变量拼写 snake_case(单/多字母皆可);函数侧隐式:注解中未绑定的小写即类型变量,作用域整条注解;不得撞 import 模块名 |

| 8 | 构造子并置 check-only(需期望类型);裸泛型构造子无自锚等式,一侧是变量即成(交叉播种) |
| 9 | 变量能力面:`==`、派生 show、搬运/存储;无序比较、无 bound、非值 |

## 1. 变量拼写(本批改定)

**类型变量 snake_case**:单字母 `t`/`u`/`e`,多字母 `elem`/`key`
皆可。类型位词法一行:**裸小写 = 变量,裸 Pascal = 声明型,点分 =
模块路径**;分类纯拼写、局部可判定。

- 函数侧隐式:注解中未绑定的小写即该函数的类型变量,作用域整条
  注解;每个声明的变量各自全新,与其他声明无关。
- **错拼防墙**:类型名恒 PascalCase(type.md §6),`Preson` 一类
  错拼仍是大写、未声明即报错;小写永不冒充类型名。大写多字母隐式
  因此是死路(错拼静默成变量),小写隐式是活路——描述名(`elem`)
  与词法安全兼得。
- 变量不得与 import 模块同名:裸 `json` 两读(变量/模块),同层
  冲突精神,编译错误。

旧案(全局单字母大写,ekoc 已实施)的三个破口,随收编改定:

1. **大小写教义**:PascalCase = 有身份(声明型、构造器、命名空
   间),snake = 绑定与模块路径(type.md §6)。变量是绑定,旧案
   让它穿身份层的衣服——"绑定即 snake"全域成立,类型域不设例外。
2. **并置自撞**:应用无分隔符,`Tree: type T` 是自然拼写,满屏
   `Tree T`、`Task T`——类型名与变量同大小写仅差尾字母;小写后
   `Tree t` 第一眼即分。
3. **名字没收**:旧案"单字母大写不可声明为类型名"为撑词法判据
   没收一整类名字;小写案零没收(PascalCase 强制已由 type.md §6
   承担)。

代价如实记:类型声明 RHS 与模式失去大小写域信号——`Ok t` 载荷
与 `Ok t` 模式同貌(位置裁定,解析无歧义,人眼扫描有代价)。

## 2. 类型声明与应用

### 2.1 binder

```
Pair:  type t u = [t, u]
Value: type t u =
    |First [u, t]
    |Second t
Tree:  type t = Leaf t | Node [Tree t, Tree t, t]
```

- 声明头保持 `名字 ':'` 不变量(一切声明形式的公共前缀);文法是
  纯扩展——`type` 与 `=` 之间原无任何合法 token,零回折风险;多行
  union 的 layout 不受影响(layout.md)。
- 应用按位填充:`Value Int Float` 即 t=Int、u=Float,`First` 载荷
  `[Float, Int]`——与变体书写顺序无关,参数顺序在使用点自答。
- binder 局部于声明 RHS。`depth: (tree: Tree t) -> Int` 中的 `t`
  是注解自己的变量,与 Tree 的 binder 同名不同域,无捕获。
- binder 必须出现在 RHS(幻影参数报错)——否则牵连 `==`、show、
  转换语义,不开口子。

动机(否决隐式"按首次出现收集"):`|First [u, t]` 的布局顺序
(变体序、字段序)重排任一者都会静默翻转远端使用点的实参含义;
union 不像括号形状那样自带位置骨架,故 binder 显式、有序。

### 2.2 应用:并置、无逗号

```
f:  (Value Int Float) -> Int        // 一个参数
xs: []Value Int Float               // 列表
ts: [Value Int Float, Bool]         // 应用链在逗号处终止
o:  Option (Value Int Float)        // 复合实参加括号(既有规则)
```

否决逗号应用 `Value Int, Float` 的决定性理由:函数参数列表本身用
逗号分隔,`(Value Int, Float) -> Int` 只能解析为两个参数,表达单参
应用须双层括号——而函数类型是类型出现最频繁的位置。次要:元组与
应用争抢同一逗号(真二义)。语言既有惯例本就是"应用用邻接、枚举
用逗号":字典 `[k]v` 无逗号,元组 `[a, b]` 有逗号(type.md §3.1)。

### 2.3 被否决备选

| 记法 | 理由 |
|---|---|
| `Value<Int, Float>` | 运算符歧义、`>>` 嵌套、无尖括号的表面断裂 |
| `Value[Int, Float]` | 与括号形状语法致命冲突 |
| `Value(Int, Float)` | 与调用式冲突 |
| `Value Int, Float` | 与函数参数列表冲突(§2.2) |
| 前置 binder `Value u t: type` | 破坏 `名字 ':'` 声明头不变量 |
| 大写多字母隐式变量 | 错拼 `Preson` 静默成变量(§1) |
| `'a`(ML 撇号) | 新词法类;仅作后路保留 |

## 3. 函数泛型

原则:**类型声明需要 binder,因为应用按位书写;函数实例化靠合一、
从不按位书写,没有槽位可定义。**

### 3.1 隐式声明与泛化点

```
first: (xs: []t) -> Option t =
    case xs:
        {x, ..rest} -> Some x
        {}          -> None

id: (t) -> t = (x): x
swap: (p: [t, u]) -> [u, t] =
    case p:
        {a, b} -> {b, a}
```

- 泛化点 = 注解绑定,顶层与块级一致。多态递归与多态互递归免费:
  类型来自注解而非推导,递归调用可按任意实例化使用——

```
even_len: (xs: []t) -> Bool =
    case xs:
        {}          -> True
        {_, ..rest} -> odd_len(rest)
odd_len: (xs: []t) -> Bool =
    case xs:
        {}          -> False
        {_, ..rest} -> even_len(rest)
```

- `:=` 不泛化:`id := (x): x` ✗(lambda 恒 check-only);多态绑定
  必须注解:`my_first: ([]t) -> Option t = first`。eko 无可变
  状态,注解即声明的泛化无可靠性风险。

### 3.2 参数绑定规则(result-only 禁止)

函数注解的每个变量必须出现在**至少一个参数类型**中,否则声明期
报错:

```
first: (xs: []t) -> Option t      // ✓
f: (g: () -> t) -> t              // ✓ t 出现在参数 g 的类型中
empty: () -> []t = {}             // ✗ t 未由任何参数确定
read: (n: Int) -> Option t        // ✗ 同上
```

理由:不依靠参数确定的类型应当是确定的。与类型侧幻影禁令**对称**
——两侧都在声明期消灭悬空变量。`empty` 无损失:空列表配合期望
类型即可(`ys: []Int = {}`,type.md §3.2)。io-world.md §5.2 的
开位 result-only 禁令是同一条(位与类型同机,§4.4)。

### 3.3 实例化

- 变量逐字绑定实参类型;使用点合一,永不写类型实参;参数绑定
  规则保证合一与期望必居其一。
- **lambda 实参最后检查**:`List.map({1, 2, 3}, (x): x * 2)` 先由
  列表实参把 t 定为 Int,再检查 lambda——否则其参数是未定变量,
  字面量 `2` 无处适配。

### 3.4 变量的活动范围与能力面

可以:参数类型、返回类型、括号形状内部、应用实参(`Tree t`)、
嵌套函数类型(`(f: (t, u) -> v, xs: []t, ys: []u) -> []v`)。
不可以:应用头(`t Int` ✗,变量是 mono kind);值层表达式(`t`
不是值,类型不出现在值位)。

函数体对 `t` 型值的操作面:

| 可用 | 依据 |
|---|---|
| `==` / `!=`(结构相等) | derive.md §4 派生 |
| 派生 show(插值、println) | derive.md §2 |
| 派生 `to_json` / `from_json` | json.md(实例化处落具体派生或覆写) |
| 绑定 / 传递 / 存储 / 模式解构 | repr 机制 |

不可用:序(`sort_by` 传显式比较子的原因;v1 无 bound 即不做
约束求解)。多态分工:

> 开放的多态 = 参数化泛型(能做的事少但处处成立);
> ad-hoc 多态 = 封闭 union + case(穷尽性检查即封闭世界分派的
> 守门人)。

## 4. 与各部位的组合

### 4.1 nominal 与实例化

`Pair: type t u = [t, u]` 声明类型族;`Pair Int String` 是其中一员,
名义身份属声明(type.md §7)。字面量与适配走既有机器:字面量经
期望类型落位(`p: Pair Int String = {1, "a"}`);名义流入同形匿名
形(实参、操作数、期望位,type.md §7.2)。**元组形适配随本档
延伸**:形适配按 RHS 形状延伸至元组形(`q: [Int, String] = p` ✓),
代数形不延伸(匿名 ADT 不存在,type.md §7.3 不变)。不同实例是
不同名义型:`Pair Int String` 与 `Pair Int Float` 互不相通。

### 4.2 构造、字面量、模式

构造子并置 check-only(需期望类型);模式 binder 的类型来自
scrutinee 的实例化;lambda 参数类型由合一给出——用户 `my_map`
与 `List.map` 调用点行为完全一致。

泛型构造子的等式:裸 `Leaf 1 == Leaf 2` ✗(无唯一 union 可自锚、
无限定形式可逃);一侧是变量即可:`t == Leaf 1` ✓(交叉播种)。
单形态 union 的裸构造子自锚(`Red == Green`)保留。

### 4.3 union:主战场

```
t: Tree Int = Node {Leaf 1, 2, Leaf 3}
depth: (tree: Tree elem) -> Int =
    case tree:
        Leaf _          -> 0
        Node {l, r, _}  -> Int.max(depth(l), depth(r))
```

- 模式匹配零新增:模式按实例化后的类型工作,穷尽性按实例化后的
  union 检查。
- 括号方向镜像:类型位 `[...]`、值位与模式 `{...}`——
  `Node [Tree t, Tree t, t]` ↔ `Node {Leaf 1, 2, Leaf 3}` ↔
  `Node {l, r, _}`。
- 递归 union(`Tree` 即是)与互递归照常;递归型声明的**表示与
  运行时**(装箱、内存管理)定案于 repr.md(2026-10:递归位恒
  指针、泛型单态化、引用计数)。

### 4.4 开位与类型变量同机

io-world.md §5.2:`?` 是位上的匿名参数,与类型变量同一台机器——
由参数喂给、调用点实例化、lambda 最后检查。幻影检查看穿 `?`
位置:`Callback: type t = (t) ?-> _` 合法,开位经 RHS 的 `?->`
出现。

## 5. 可读性

- 认出泛型靠一条词法规则:类型位裸小写恒为变量(§1);大小写即
  域信号——类型名大写、变量小写、模块点分。
- 声明处 binder 显式有序,使用点按位对应——无需扫 RHS、无需
  工具回显;工具诉求只剩函数侧(hover 泛化方案、错误消息点名
  "类型变量")。
- C 家族用户的第零周由 prelude 化解:标准库通篇即此记法,第一天
  就在学。
- 实例化靠合一,使用点几乎不写类型实参;辨认场合只剩读签名与写
  注解,恰是此记法最舒服的位置。

## 7. 速查

```
Pair: type t u = [t, u]        // binder;应用按位
Value Int Float                // 并置应用,无逗号
Tree: type t = Leaf t | …      // t 小写;Tree t 第一眼即分
f: (g: () -> t) -> t           // ✓ t 见于参数类型
empty: () -> []t               // ✗ result-only 变量
Value: type t u = Second t     // ✗ 幻影参数 u
xs: []Value Int Float          // 应用链在逗号处终止
Node {l, r, _}                 // 模式按实例化工作
t == Leaf 1                    // ✓ 交叉播种;Leaf 1 == Leaf 2 ✗
```
