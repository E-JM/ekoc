## 1. 为什么没有循环

主轴一句:**控制流是机器原语(case/if/调用),迭代是库函数。**

- 值不可变(expr.md):循环变量是可变状态的仪式,自增自减无处生根;
  累加器作为参数传递——同一形状,零赋值。
- 循环体干两件事——"对每个"与"怎么合"——each/fold 各管一件:
  名可 grep,位透明(`?` 分派者),实现可换。
- 语法经济:case/if/调用已是全部控制流;`while` 是隐式 goto。
- 组合子可组合(`xs.filter(f).map(g)`,call.md §5),语法循环
  不可组合。

## 2. 三词汇与栈保证

| 词汇 | 形 | 栈保证 |
|---|---|---|
| 组合子 | `xs.each/map/filter/fold/…`、`(1..=n).fold` | 原生迭代,任意长度(规范级) |
| 自尾递归 | 函数尾位调用自身 | 恒优化为跳转(规范级) |
| 其余递归 | 结构递归、相互递归、非尾调用 | 无承诺,栈深随数据深 |

```eko
// for 形 → Range 组合子
sum_to: (n: Int) -> Int = (1..=n).fold(0, (acc, i): acc + i)

// while 形 → 自尾递归 + 卫式
count_down: (out: Out, n: Int) ! =
    if n > 0:
        out.println(show(n))
        count_down(out, n - 1)            // 自尾:跳转,栈恒定

// 结构递归 → 模式谱(pattern.md §3);写意形,深列表冒栈险
sum: (xs: []Int) -> Int =
    case xs:
        {}       -> 0
        {h, ..t} -> h + sum(t)            // 非尾;日常用 List.fold

// 同一函数的自尾形:累加器进参数,私有助手
_sum: (xs: []Int, acc: Int) -> Int =
    case xs:
        {}       -> acc
        {h, ..t} -> _sum(t, acc + h)      // 自尾:栈恒定

// 死循环 → Never 递归(never.md §5)
spin: () -> Never = spin()
```

迭代替换表:

| 循环习惯 | eko 词汇 |
|---|---|
| 计数 for | `(a..=b).each/map/fold`(Range 组合子) |
| 遍历 for | `xs.each/map/…`(列表组合子) |
| while | 自尾递归 + 卫式 if(累加器进参数) |
| break | `find_by`/`any`/`all`——首中即停的收束 |
| continue | `filter` 预筛,或卫式分支 |
| 无限 loop | `-> Never` 递归,有类型有故事 |

## 3. TCO 承诺(规范级)

**函数尾位对自身的调用,编译为同一栈帧内的控制流转移;栈空间与
递归次数无关。**一切合规实现必须保证。

- 尾位清单:块末表达式、case 各臂、if 两臂;运算符糖展开后判定
  (`a \|\| b` 的 `b` 随 if 臂入尾位)。回调体的末位是**该回调**的
  尾位,不是外围函数的——lambda 各有各的箭头(lambda.md)。
- 与位、泛型正交:位与类型皆擦除(io-world.md §5.2),尾调用是
  纯控制流事实。
- 如实记:已消除的帧不出现在 panic 回溯——这是优化的可观察代价,
  诚实在档。

## 4. 不承诺面

- **相互递归**:模块内自由(module.md 裁定 7),栈不保证——递归
  下降一类,深度随输入结构:

```eko
even: (n: Int) -> Bool = if n == 0: True else: odd(n - 1)
odd:  (n: Int) -> Bool = if n == 0: False else: even(n - 1)
// 合法;深链冒栈险——浅域惯用,深域改自尾或组合子
```

- **跨函数尾调用**:尽力优化,不作规范承诺——后端尾调用保证
  参差,承诺只写可实现面,不写空头支票。
- **非尾递归**:栈随数据深;深数据先问组合子能否表达。
- **栈溢出**:即中止,进程级 abort,不可捕、不是 panic(B4 非承诺
  清单的近亲);诊断尽力,粒度属实现域。

## 5. 与既有档的接缝

- pattern.md §3:列表模式 + 递归是自定义遍历之骨。
- io-world.md §10:分派者清单即迭代标准库;`?` 使迭代与涉世回调
  自由组合:`persons.each((p): out.println(show(p)))`。
- never.md:死循环有词汇——`-> Never` 递归。
- module.md 裁定 7:模块内递归绑定自由;跨模块相互递归已禁。

## 6. 禁止清单

- **while/for/do-while/loop 关键词**——三词汇覆盖;循环变量是
  可变状态。
- **break/continue**——提前收束是组合子语义(find_by/any/all),
  不是控制流原语。
- **尾调用承诺扩大到跨函数**——诚实承诺可实现面;空头支票毁
  "承诺"一词的信用。
- **生成器/yield**——惰性序列另立裁定,不因循环缺席而补位。

## 7. 速查

```
(1..=n).fold(0, (acc, i): acc + i)      // for + 累加

xs.find_by(f); xs.any(f); xs.all(f)     // break 的词汇
spin: () -> Never = spin()              // 死循环的词汇
```
