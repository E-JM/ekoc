## 1. 运算符:糖与封闭集

```
a + b    ≡  Int.add(a, b)        // 数值域;UInt/Float 同构
a % b    ≡  Int.rem(a, b)
a < b    ≡  Int.lt(a, b)         // 产 Bool
a && b   ≡  if a: b else: False
a || b   ≡  if a: True else: b
-a       ≡  Int.neg(a)
xs ++ ys ≡  List.append(xs, ys)    // 连接;字典合并后胜、字符串/字节串连接同构
```

UFCS 恒等式照常成立:`a.add(b)`、`x.neg()` 与运算符形同权(call.md §1)。
重载即命名空间:符号按操作数类型落进对应类型命名空间,无第二套
重载机制。集合封闭:无位运算、无 `**`、无自增自减(值不可变)、无
三元——`n = if c: 0 else: x` 已是表达式(branch.md §3)。连接、位算、
幂走函数(`List.append`;位算随 FFI 波次)。

`++` 细则:域为列表、字符串、字节串(连接)与字典(合并,后胜);元组禁
(变型),记录禁(部分字面量只在 with 实参位,derive.md §6);元素
不自动包装——`prefix ++ {x} ++ suffix`,typed 不猜。

一条可教学的主轴:**记号 = 机器原语与短路;函数 = 其余一切**。

## 2. 算术

- `/` `%` 截断向零,同基成对:`-7 / 2 = -3`,`-7 % 2 = -1`(LLVM
  `sdiv`/`srem` 直映)。floor 族是函数:`Int.div`/`Int.mod`
  (`-7 → -4, 1`,余数随除数符号;SML/Haskell 双对同构)——数学、
  日历、环域用之。UInt 域无此歧义,非负取模的正确域是 UInt。
- 溢出、除零(含 `Int.min / -1`)panic(B4 不入位;索引越界已非 panic——索引即域检查,access.md);
  环绕需求将来走 `Int.wrapping_*` 另立。
- `%` 覆盖数值域;Float 同 trunc 基(`fmod`)。
- 无隐式转换:`1 / 2.0` 是类型错误;显式走 `Int.to_float()`、`UInt.to_int()`
  一类命名空间函数;后者超 `Int.max` 返回 None,三分法见 convert.md。

## 3. 逻辑

`&&`/`||` 必须惰性——短路即分支,故是 if 的糖,位照 branch.md §6
透明 OR 进外围:

```eko
if fs.exists(path) && size > 0:      // 右操作数涉世,照常置位
    …
```

`not` 无需惰性,故是函数:`b.not()`、`Bool.not(b)`;`!` 永属 world
位(io-world.md §5.4),不设 `!x`。为何符号而非 `and`/`or`/`not`
单词:单词永久退役三个标识符、堵死 `Bool.and`/`Bool.not` 成员名、
破"关键词全为块开头词"的格局;符号零占用,单形 `&`/`|` 仍自由
(位算、或模式将来分位而入)。中文读者对符号与英文单词同为学来
的记号,符号紧凑中立。

## 4. 优先级与结合

| 级 | 运算 | 结合 |
|---|---|---|
| 1 | 后缀:`.f()` | 左 |
| 2 | 一元 `-` | — |
| 3 | `* / %` | 左 |
| 4 | `+ - ++` | 左 |
| 5 | `== != < <= > >=` | **无(禁链)** |
| 6 | `&&` | 左 |
| 7 | `\|\|` | 左 |

- **链式比较是解析错误**:`a < b < c` 不入文法——C 的经典陷阱,
  写 `a < b && b < c`。
- `-x.f()` 是 `-(x.f())`,后缀先行。
- `b.not()` 是后缀函数调用,天然先于一切运算符。

## 5. Bool 与比较

```
Bool: type = True | False          // prelude ADT
```

- 条件、卫式皆 Bool,无 truthy 强转(branch.md §3 既有裁定);
  `True`/`False` 是唯一构造器。
- `==`/`!=`/`<`… 产 Bool,按操作数类型落命名空间
  (`Int.eq`、`String.lt`);**两边同型**(derive.md §4);capability
  无 `==`(io-world.md §2)。用户类型的 `==` 与 `<` 由派生服务承担
  (derive.md)。

## 6. 数值域:域词与机词

| 面 | 名 | 意 |
|---|---|---|
| 今日面 | `Int` `UInt` `Float` | **域词**,定宽 64(= Int64/UInt64/Float64,非平台字长——确定性) |
| FFI 面 | `I8 I16 I32 I64`、`U8…U64`、`F32 F64` | **机词**,缩写即"机器边界"信号,与 C 头的 `i32/u32` 对眼;随 FFI/二进制波次入域 |

全拼 = 域,缩写 = 机界——两个原则各归其位:域词给人读(`age: UInt`
读作"年龄是自然数"),机词与 C 头对译。bignum 默认拒:UInt 首要类型、
FFI 映射、零成本擦除气质三处相悖;溢出 panic 是诚实的便宜。
`1` 是 Int,`1.5` 是 Float,不同型无强转。

## 7. 字面量与插值

```eko
age: UInt     = 36
big: Int      = 1_000_000          // _ 分组
pi:  Float    = 3.14159
k:   Float    = 1.5e3              // 含 . 或指数即 Float
c:   Char    = '中'               // 单引号;Unicode 标量值
s:   String   = "line\n"
greet: String = "hi {name}, n={n}" // 插值
```

- 整数十进制;`0x`/`0b` 随位运算档另立。
- **Range 两形**:`a..b` 开端、`a..=b` 含端,产 `Range Int`(prelude);
  中缀低于后缀,链上括号:`(1..=100).map(f)`;词法:整数字面后随
  `..` 不入浮点。今日域 Int/UInt;Float、步长、无界另立。Range 函数
  见 io-world.md §10(each/map 为 `?` 分派者)。
- **插值槽 `{e}` = `show(e)` 注入**(显示通道,可覆写;结构通道
  `inspect` 见 derive.md)——`"io: {err}"` 的 IoError 展示由此成立;
  `show` 全域(capability 显示 `<cap>`)。
- 转义:`\{` `\n` `\\` `\"`;Char 同规加 `\'`;括号内折行照 layout.md。
- 字符串 UTF-8,双引号,单行;多行串暂无(YAGNI,`\n` 足够)。Char
  字面量单引号,元素域、索引与桥见 char.md。

## 8. 注释

`//` 行注释;无块注释(嵌套自由是伪需求,删除即重写)。
全档案注释已统一 `//`(need.md 项就此关闭)。
2026-10 增订 `///` 文档注释,need.md 小规范洞就此关闭。

**`///` 文档注释**:挂紧随其下的绑定(顶层与块级皆可,
`type`/`test`/`main` 同权);连续多行聚合为一篇;内容自由文本。
零语义——`///` 不参与编译,且不消警(diag.md)。doc 工具链(抽取与
渲染)属工具域,测试运行同款(test.md §6);语法面就此一个词。

## 9. 速查

```
1 + 2 * 3                 // 7,优先级如常
-a ** 拒                  // 无 ** 而无此歧义;幂走 Int.pow
7 / 2                     // 3;-7 / 2 → -3(截断)
7 % 2                     // 1;-7 % 2 → -1
Int.div(-7, 2)            // -4;Int.mod(-7, 2) → 1(floor 族)
a < b && b < c            // 禁链的显式写法
if a && b || c: …         // || 最松
b.not()                   // 函数;!x 不存在
xs ++ ys ++ {7}            // 连接;元素要包 {7}
defaults ++ overrides     // 字典合并,后胜
(1..=100).map(f)          // range 中缀低于后缀,链上括号
"{i}: {p}"                // show 注入
xs.get(i)                 // Option;域检查,唯一入口(access.md)
```
